[4] การตัดสินใจออกแบบ + เหตุผล  ** อ่านก่อนแก้โค้ด **
----------------------------------------------------------------
4.1 Snapshot detail_text
    เก็บข้อความจริงลงตารางธุรกรรมเลย ไม่ JOIN detail_master ตอนอ่าน
    WHY: ข้อมูลเก่าไม่เปลี่ยนตามการแก้ชื่อใน master
         + ผู้ใช้พิมพ์เองได้โดยไม่ต้องเพิ่มเข้า master ก่อน
    >> อย่าเปลี่ยนไปใช้ JOIN ล้วน

4.2 Portable Clinic Category
    จับคู่หมวด "คลินิก" ด้วยชื่อ String ไม่ใช่ ID
    WHY: ย้ายไฟล์ DB ข้ามเครื่องแล้วยังทำงานถูก แม้ ID ไม่ตรงกัน
    >> อย่า optimize ไปใช้ ID

4.3 Thai Display via WebView
    ใช้ HTML Table แทน monospace text
    WHY: ฟอนต์ไทยบน iOS ความกว้างไม่คงที่ จัดคอลัมน์ด้วย space ไม่ตรง

[7] SNIPPET — KEYBOARD AVOIDANCE (พร้อมใช้)
----------------------------------------------------------------
แนวทาง: ไม่ใช้ objc_util ใช้ delegate event ของ ui module
แผนนำไปใช้: แยกเป็นโมดูลกลาง keyboard_helper.py
            ให้ income_entry.py และ expense_entry.py import ร่วมกัน

# --- keyboard_helper.py ---
import ui

def get_keyboard_height():
    w, h = ui.get_screen_size()
    return 340 if min(w, h) >= 700 else 300   # iPad / iPhone

def adjust_button_position(button, parent_view, keyboard_up):
    kb_h = get_keyboard_height()
    if keyboard_up:
        target_y = max(0, parent_view.height - kb_h - 52)  # guard กันติดลบ
    else:
        target_y = parent_view.height - 55

    def _anim():
        button.y = target_y
    ui.animate(_anim, 0.25)      # 0.25s = จังหวะเดียวกับคีย์บอร์ด iOS

class KeyboardAwareDelegate:
    def __init__(self, button, parent_view):
        self.button = button
        self.parent = parent_view
        self.editing = False

    def textfield_did_begin_editing(self, textfield):
        self.editing = True
        adjust_button_position(self.button, self.parent, True)

    def textfield_did_end_editing(self, textfield):
        self.editing = False
        ui.delay(self._maybe_lower, 0.08)

    def _maybe_lower(self):
        if not self.editing:
            adjust_button_position(self.button, self.parent, False)

ข้อควรระวัง:
- ต้องใช้ delegate INSTANCE เดียวกันกับทุก TextField ในหน้านั้น
  ไม่งั้น flag self.editing จะแยกกันคนละตัวและกันปุ่มเด้งไม่ได้
- ปุ่มที่จะเลื่อนต้องไม่ตั้ง flex='B' เพราะจะชนกับการเซ็ต .y เอง
- ถ้ามีหลายปุ่ม ให้ห่อไว้ใน ui.View เดียว (footer bar) แล้วเลื่อน container

ทางเลือกสำรอง (ควรมีคู่กันเสมอ):
- ปุ่มบันทึกบน title bar ผ่าน right_button_items -> คีย์บอร์ดบังไม่ได้
- Tap to dismiss : ui.View โปร่งใสเต็ม parent เรียก view.end_editing()
  (วางไว้หลังสุดด้วย send_subview_to_back กันบังปุ่มอื่น)
